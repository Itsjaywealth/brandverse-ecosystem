# Security Policy

## Private reporting

Please do not publish security vulnerabilities, credentials, tokens, private keys, customer information, production configuration or internal infrastructure details in a public GitHub issue.

Use GitHub's **Report a vulnerability** private reporting flow for this repository when available.

## Public repository boundary

This repository is intentionally limited to public-safe portfolio, product and architecture documentation for the BrandVerse ecosystem.

Production application source, credentials, private environment configuration, customer/order data, private analytics, internal endpoints and confidential operational runbooks remain outside this repository.

If sensitive material is ever committed, contain the exposure first, revoke or rotate affected credentials where applicable, remove the material from reachable history, and re-scan before considering the incident closed.
