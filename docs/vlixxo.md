# Vlixxo

**Live:** https://www.vlixxo.com

**Public repository:** https://github.com/Itsjaywealth/vlixxo.com

Vlixxo is a multi-category ecommerce storefront operated within the BrandVerse ecosystem.

## Public product scope

The customer experience includes catalogue and category browsing, search and product discovery, visual product search, product detail pages, cart flows, regional shopping behaviour and checkout handoff.

BrandVerse operates the broader commerce system around catalogue quality, merchandising, supplier workflows, search and discovery, checkout and fulfilment.

## Public technology profile

Verified high-level technologies include:

- React
- Vite
- Node.js
- Express
- MongoDB with Mongoose
- Shopify commerce integration

## Repository boundary

Vlixxo has a separate public documentation/showcase repository. The authoritative production application source and operational tooling remain private.

No supplier authentication, payment credentials, customer/order data, database credentials or private infrastructure configuration is published in the public repository.
